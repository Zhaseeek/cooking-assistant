 Cooking Assistant

A web application that helps users discover recipes based on available ingredients and dietary preferences.

https://cooking-assistant-gl8f.onrender.com/



- Search for recipes based on available ingredients
- Filter recipes according to dietary preferences
- Web-based user interface
- Recipe dataset processing
- Recipe recommendations



- Python
- Flask
- Pandas
- HTML
- CSS
- JavaScript


- `app.py` — main Flask application
- `templates/` — HTML templates
- `static/` — CSS, JavaScript and static files
- `clean_recipes.csv` — recipe dataset
- `requirements.txt` — Python dependencies
